4.1 Accessibility Help Text in APEX

Accessibility help text is available in Oracle APEX. Reference this text when designing your application.

When using Page Designer, selecting an attribute and then clicking the Help tab displays Page Designer Help for that attribute. The Help tab describes what the attribute is for as well as available options for that attribute.

Accessibility-focused help text is incorporated into key attributes within Page Designer Help, identified with the heading "Accessibility" and an icon. The accessibility help text covers crucial accessibility aspects including alt text, color contrast, row headers for reports, labels, and descriptions.

Description of the illustration accessibility_help_text.png

Reference the accessibility help text for clear and actionable guidance when developing APEX apps.

For more information on using Page Designer, see About Page Designer in Oracle APEX App Builder User’s Guide.
