3.1.1 Enabling Accessibility Tags in PDF Documents

Toggle accessibility tags for PDF documents with the APEX_UTIL.SET_PREFERENCE procedure.

Creating an accessible PDF enables the document to be read aloud by a screen reader and other text-to-speech tools and increases the PDF file size. Setting the p_preference parameter APEX_PDF_ACCESSIBLE to Y adds accessibility tags for native PDF printing. Alternately, setting APEX_PDF_ACCESSIBLE to N disables accessibility tags. This preference is set automatically when the Include Accessibility Tags switch is enabled in the download dialog of an interactive report or interactive grid.
