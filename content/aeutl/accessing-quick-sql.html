5.4.2 Accessing Quick SQL

Access Quick SQL by clicking SQL Workshop, Utilities, and then Quick SQL.

To access the Quick SQL page:

  1. On the Workspace home page, click the SQL Workshop icon.
  2. Click Utilities.
  3. Click Quick SQL.

    The Quick SQL page appears. To learn more, see About the Quick SQL Page.

Tip:

You can also access Quick SQL on the SQL Scripts page by clicking the Quick SQL button. See Using SQL Scripts.
