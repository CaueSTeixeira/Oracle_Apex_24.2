5.1.4 Accessing the Load Data and Unload Data Wizards

Access the Load Data or Unload Data wizards in SQL Workshop by clicking Utilities and then Data Workshop.

Use Data Workshop page to load data from various file formats such as XLSX, CSV, XML, and JSON into your workspace. You can also use the Unload Data wizard to export your data in text or XML format.

To access Load Data or Unload Data wizards:

  1. On the Workspace home page, click the SQL Workshop icon.
  2. Click Utilities.
  3. Click Data Workshop.

    The Data Workshop page appears.

  4. Click the appropriate icon to load data and unload data:
    • Load Data
    • Unload Data
