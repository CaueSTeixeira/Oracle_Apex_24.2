5.2.4 Running Blueprints

Quickly run a blueprint on the Data Generator home page or generate data in Blueprint Designer.

  • Selecting Data Generation Schema
    On the Data Generator home page, click the drop-down list under Data Generation Schema to select the database schema to be used for data generation. The Data Generator home page reloads.
  • Generating Data from a Blueprint
    Click the corresponding Generate Data button for the blueprint you want to populate with sample data. For valid tables, you can generate an exportable file or insert the data into corresponding tables in the workspace.
