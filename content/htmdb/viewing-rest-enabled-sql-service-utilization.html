18.5.8 Viewing REST Enabled SQL Service Utilization

View where a REST Enabled SQL Service is being used within a workspace on the REST Enabled SQL Utilization report.

To view the REST Data Sources Utilization report:

  1. Navigate to the REST Data Sources page:
    1. On the Workspace home page, click App Builder.
    2. Click Workspace Utilities.
    3. On the Workspace Utilities page, click REST Enabled SQL Services.

    Tip:

    You can also access the REST Enabled SQL page from Shared Components. On the App Builder home page, select the application and then click Shared Components. Find Workspace Objects and click REST Enabled SQL Databases
  2. On the REST Enabled SQL page, click Utilization.
    The Utilization page displays where a REST Enabled SQL Service is being used within the workspace.
