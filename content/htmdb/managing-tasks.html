20.15 Managing Tasks

Manage tasks by configuring task definitions, task details, and unified task lists. Use page processes to create approval tasks or action tasks.

  • Managing Task Definitions
    Task Definitions set up the structure for a particular set of tasks, including participants, parameters, and actions.
  • Managing Task Details
    Task Details display when you open the task instance.
  • Managing Unified Task Lists
    The Unified Task List allows workspace users to view and manage their tasks.
