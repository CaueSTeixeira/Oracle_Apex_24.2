19.4 Manually Refreshing Oracle APEX Components

Use the apex.region().refresh() method to refresh the content of a region that supports being refreshed.

Although the Dynamic Action framework provides refresh capability for supported APEX components, there may be cases where you wish to manually invoke a refresh from JavaScript code. To do this, use the apex.region().refresh() method as follows: 

apex.region("myRegionStatidID").refresh();
