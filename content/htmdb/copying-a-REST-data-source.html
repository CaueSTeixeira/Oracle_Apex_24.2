18.4.6 Copying a REST Data Source

Copy a REST Data Source by selecting Copy on the REST Data Sources page.

To copy a REST Data Source:

  1. Navigate to the REST Data Sources page:
    1. On the Workspace home page, click App Builder.
    2. Select an application.
    3. On the Application home page, click Shared Components in the center of the page.
    4. Under Data Sources, select REST Data Sources.
  2. On the REST Data Sources page, click Copy.
  3. On Copy REST Data Source:
    1. Copy REST Data Source - Select an existing REST Data Source.
    2. New REST Data Source Name - Enter a new name.
    3. Click Copy.
