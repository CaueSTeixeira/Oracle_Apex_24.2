3.5 How Oracle APEX Uses Templates

Learn how Oracle APEX uses templates to construct the appearance of application pages.

The APEX engine constructs the appearance of each page in an application using templates. Templates define how pages, page controls, and page components display. This topic describes the various ways you can use templates to control and refine the appearance of application pages.

  • Basic Templates
    Templates in Oracle APEX support the use of substitution strings to pass information and replace any character string with another value.
  • Theme Templates
    Learn about the Universal Theme and how to control application layout using theme styles, Theme Roller, and template options.
  • Accessing the Universal Theme Reference App
    Run the Universal Theme Reference app to learn about features and best practices when using the Universal Theme.
  • Template Components
    Use Template Components to create reusable UI components that work in Page Designer like any other plug-in.
  • Template Directives
    Template directives are special tokens in a template that control how the text around them is processed.
