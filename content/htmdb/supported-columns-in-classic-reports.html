8.10.2 Supported Columns in Classic Reports

Learn about column types supported by classic reports.

Classic reports support the following column types. To view the column type in Page Designer, select the column and find the Identification, Type attribute in the Property Editor.

Note:

You can also view this information in Page Designer Help. View the page containing the report in Page Designer. Select a column and then Identification, Type attribute. Click the Help tab in the central pane.
Column Type Description
Plain Text Displays the column value.
Plain Text (based on List of Values) Displays the value returned from the list of values specified.
Rich Text Renders the column using HTML or Markdown.
Link Displays the column as a link.
Display Image Displays the column as an image.
Download BLOB Displays the column as a link to download the file.
Percent Graph Displays the column as a percentage graph. The value retrieved must be between 0 and 100.
Hidden Does not display the column, but it is referenceable.
