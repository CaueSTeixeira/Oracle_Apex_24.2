22.7 Translating Messages

Learn when and how to translate messages in an Oracle APEX application.

  • About Translating Messages
    Learn about when to translate text messages in your application.
  • About Translating Messages Used in PL/SQL Procedures
    Learn about translating messages used in PL/SQL procedures.
  • Translating Messages Used Internally by APEX
    If your application uses a language that is not among the standard languages into which APEX is translated, you must translate messages displayed by the APEX runtime engine.

    Create, edit, copy, or subscribe to text messages by selecting the application and navigating to Shared Components, Globalization, Text Messages.
