10 Managing Application Components

Oracle APEX supports the creation the following application components: calendars, maps, charts, and application Help.

  • Understanding Oracle JET Integration with Oracle APEX
    Oracle APEX includes the Oracle JET (JavaScript Extension Toolkit) library. This section provides information about JET and how it is integrated with APEX.
  • Creating Calendars
    App Builder includes support for creating a calendar with monthly, weekly, daily, and list views. Once you specify the table on which the calendar is based, you can create drill-down links to information stored in specific columns and enable drag and drop capability.
  • Creating Charts
    Create charts in App Builder by running a built-in wizard or by creating them manually in Page Designer.
  • Creating Maps
    Create maps that visualize location data (real coordinates) based on data in a table.
  • Creating Help for Your Application
    Help created in App Builder displays on a dedicated Help page. To access Help, users click a link that takes them to a dedicated Help page. This Help page displays page and field-level Help topics specific to the page they are viewing.
