20.11 Workflow Views

Learn about workflow metadata views and workflow runtime views.

Workflow metadata views provide information about the workflow definition at design time. The metadata views represent the workflow model in workflow designer, including the activities, parameters, variables, and participants of a workflow definition.

Workflow runtime views contain information about specific workflow instances. You can use workflow runtime views to query the current state of an active workflow instance, or to query the history of a completed workflow instance.
