11.2.11 About Exporting and Importing Themes

Export a theme in the same way you export any related application files.

Exporting a theme from one development instance to another involves the following steps:

  1. Create an application using the theme. See Creating Applications.
  2. Export the theme. See Exporting Themes.
  3. Import the exported file into the target APEX instance. See Importing Export Files.
  4. Install the exported file from the Export Repository. See Managing Export Files from the Export Repository.
