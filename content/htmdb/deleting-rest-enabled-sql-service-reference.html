18.5.7 Deleting a REST Enabled SQL Service Reference

Delete REST Enabled SQL references on the Edit page by clicking Delete.

You cannot delete a REST Enabled SQL reference if it is being used by an APEX component.

To edit a REST Enabled SQL service:

  1. Navigate to the REST Enabled SQL page:
    1. On the Workspace home page, click App Builder.
    2. Click Workspace Utilities.
    3. On the Workspace Utilities page, click REST Enabled SQL Services.

    Tip:

    You can also access the REST Enabled SQL page from Shared Components. On the App Builder home page, select the application and then click Shared Components. Find Workspace Objects and click REST Enabled SQL Databases

    The REST Enabled SQL page appears listing the Remote Server Name, Base URL, and Authentication.


    Description of the illustration rest_enabled_sql_page.png
  2. Click the remote server name.
    The Edit page appears.
  3. Click Delete.
