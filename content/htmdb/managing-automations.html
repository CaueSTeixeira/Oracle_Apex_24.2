19.5 Managing Automations

Automations initiate a sequential set of actions based on a schedule.

  • About Automations
    Automations are a sequential set of actions, triggered by query results that monitor data and then perform the appropriate action.
  • About Importing and Exporting Automations
    After importing an application, automations are disabled. Learn how to enable automations after importing.
  • Creating an Automation
    Create an automation as a Shared Component on the Automations page.
  • Editing an Existing Automation
    Edit an existing automation on the Automation page.
  • Managing the Automation Execution Log
    View and clear the Automation Execution Log records on the Automations, Execution Log page.
  • Viewing the Automation History Report
    View recent automation modifications on the Automations History report.
