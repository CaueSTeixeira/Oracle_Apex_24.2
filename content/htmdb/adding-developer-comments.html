5.15.1 Locating Developer Comment Button

Locate the Developer Comment button.

The Developer Comment button resembles a small word balloon. This button displays on most pages in App Builder that relate to a specific application or application page.

5.15.2 Adding Developer Comments to an Application

Add developer comments to an application, a page, or a group of pages.

To add a developer comment:

  1. On the Workspace home page, click the App Builder icon.
  2. Select an application.
  3. Click the Developer Comment button.
  4. In Comment, enter up to 4000 characters of text.
  5. Click Create.

Parent topic: Adding Developer Comments

5.15.3 Viewing and Editing Developer Comments

Click the Developer Comment button to view or edit existing comments.

To edit a developer comment:

  1. On the Workspace home page, click the App Builder icon.
  2. Select an application.
  3. Click the Developer Comment button.
  4. Click View Comments.

    The Developer Comments page appears.

  5. Locate the comment to be edited.
  6. Click the Edit icon.

    The Edit Comment page appears.

  7. In Comment, enter up to 4000 characters of text.
  8. Click Apply Changes.

Tip:

You can also view and edit Developer Comments on the Shared Components page. Navigate to the Shared Components page and click Developer Comments in the Tasks region.

5.15.4.1 Deleting a Specific Developer Comment

Learn about deleting a developer comment.

To delete a developer comment:

  1. On the Workspace home page, click the App Builder icon.
  2. Select an application.
  3. Click the Developer Comment button.
  4. Click View Comments.

    The Developer Comments page appears.

  5. Locate the comment to be deleted.
  6. Click the Edit icon.

    The Edit Comment page appears.

  7. Click Delete.

Parent topic: Deleting Developer Comments

5.15.4.2 Deleting Multiple Developer Comments

Learn about deleting multiple developer comments.

To delete multiple developer comments:

  1. On the Workspace home page, click the App Builder icon.
  2. Select an application.
  3. Click the Developer Comment button.
  4. Click View Comments.
  5. Click Delete Comments.
  6. Select one of the following actions:

    • Delete all comments

    • Delete comments created by a developer

    • Delete comments by date

  7. Follow the on-screen instructions.

5.15.5 Accessing the Developer Comments from Shared Components

Access the Developer Comments page from Shared Components.

To view and edit Developer Comments from Shared Components:

  1. On the Workspace home page, click the App Builder icon.
  2. Select an application.
  3. Click Shared Components.
  4. Under Tasks, click Developer Comments.

    The Developer Comments page appears.

  5. Locate the comment to be edited.
  6. Click the Edit icon.

    The Edit Comment page appears.

  7. In Comment, enter up to 4000 characters of text.
  8. Click Apply Changes.

Parent topic: Adding Developer Comments

5.15.6 Viewing the Developer Comments Calendar

View the Developer Comments Calendar page.

To view the Developer Comments in a calendar:

  1. On the Workspace home page, click the App Builder icon.
  2. Select an application.
  3. Click Shared Components.
  4. Under Tasks, click Developer Comments.

    The Developer Comments page appears.

  5. Click Developer Comments Calendar.

    The Developer Comments Calendar page appears.

  6. Use the Previous, Today and Next buttons to navigate.
