C Directory Structure When Splitting Export Files into Separate Scripts

Exporting an application, page, or component as separate files creates a directory structure organized by component type.

This directory structure may extend multiple levels. This directory structure is the same whether you are using the application-level flag, Split into Multiple Files, or the page or component-level flag, Export as Zip.
