22.7.3 Translating Messages Used Internally by APEX

If your application uses a language that is not among the standard languages into which APEX is translated, you must translate messages displayed by the APEX runtime engine.

The APEX runtime engine which is used by developers to create applications is available in the following languages: Arabic, Brazilian Portuguese, Croatian, Czech, Danish, Dutch, Finnish, French, French - Canada, German, Greek, Hebrew, Hungarian, Italian, Japanese, Korean, Norwegian, Polish, Portuguese (Portugal) (pt), Romanian, Russian, Serbian - Cyrillic, Serbian - Latin, Simplified Chinese, Slovak, Slovenian, Spanish, Swedish, Thai, Traditional Chinese, Turkish, Ukrainian, and Vietnamese.

To support additional languages not covered in the above list, developers must provide their own translations. For example, if you develop a Bulgarian application and want to include report messages, such as pagination, in Bulgarian, you must translate the strings used in messages displayed in reports.
