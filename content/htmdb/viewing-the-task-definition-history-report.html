20.15.1.6 Viewing the Task Definition History Report

The Task Definition History Report shows recent modifications made to Task Definitions.

To view the Task Definition History Report:

  1. Select the application.
  2. Navigate to the Task Definition page:
    1. On the Application home page, click Shared Components.
    2. Under Workflows and Automations, select Task Definitions.
  3. Select History.
    The Task Definition History Report appears.
The History Report displays recent modifications made to Task Definitions in the current application.
