20.3 Copying a Workflow

Copy a workflow from another application in Shared Components.

To copy a workflow:

  1. Select an application.
  2. Navigate to the Workflows page:
    1. On the application home page, select Shared Components.
    2. Under Workflows and Automations, select Workflows.
  3. Click Copy from Other App.
    The Copy Workflow wizard opens.
  4. Select the application to copy the workflow from.
  5. Select the workflow to be copied.
  6. Specify the workflow Name.
    The name must be unique for the application.
  7. Specify the workflow Static ID.
    The static ID must be unique for the application.
  8. Click Copy Workflow.
The workflow, along with all its versions, parameters, activities, participants, variables, and shared components is copied from the selected application to the current application. If the copied workflow invokes one or more workflows, the invoked workflows are also copied to the current application if they are not already present.
