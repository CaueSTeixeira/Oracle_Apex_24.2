10.4.7.1 About Supported Map Background Types

Learn about supported map background types.

App Builder supports the following map background types:

  • Vector Tile Layer - Requires an URL that points to the style.json file describing the map layer.
  • Raster XYZ Tile Layer - Requires an URL to fetch the raster tile layer where values for x, y, and z can be specified.
  • OGC WMS - Points to an URL from the Web Map Service, from the Open Geospatial Consortium.
