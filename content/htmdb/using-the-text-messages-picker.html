22.7.4.4 Selecting Translation Messages in Page Designer

Learn about searching for and selecting translation text messages in Page Designer.

Select translation text messages directly in Page Designer by clicking the Text Messages icon or by triggering the Suggestion Box HTML Code Editors.

To search for or select translation text message in Page Designer:

  1. Create translation text messages in Shared Components. See Creating Text Messages.
  2. View the page in Page Designer:
    1. On the Workspace home page, click the App Builder icon.
    2. Select an application.
    3. Select a page.
    Page Designer appears.
  3. Enable the Text Message Picker:
    1. On the Page Designer toolbar, click Utilities.
    2. Click Show and then Text Message Picker.

      When Text Message Picker is enabled, the Text Messages icon displays next to all text fields as shown in the following example.



      Description of the illustration text_message_picker_icon.png

  4. To search for or select text messages in Page Designer:
    1. Click the Text Message icon ().
    2. To search for a text message, enter keywords in the Search field and click Go.
    3. Select the text message and edit the attribute.

      When a text message is used in an attribute, a preview of the content displays below it as shown in the following example:



      Description of the illustration text_message_preview.png

  5. To search for and select text messages in a Code Editor:
    1. Expand the Code Editor by clicking the Code Editor icon ().
    2. In the Code Editor enter &{ or &APP_TEXT$ and a suggestion box displays.


      Description of the illustration code_editor_suggestion_box.png

      Note:

      &{ only works for applications with a Compatibiltiy Mode of 24.2 or higher. See Editing the Application Definition.
