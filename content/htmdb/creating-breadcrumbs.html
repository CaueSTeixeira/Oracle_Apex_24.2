14.3 Creating Breadcrumbs

Breadcrumbs provide hierarchical navigation and display as a list of links.

  • About Breadcrumbs
    Use breadcrumbs to create hierarchical list of links that indicates where the user is within the application from a hierarchical perspective.
  • Creating a Breadcrumb While Creating a Page
    Create a breadcrumb when creating a new page.
  • Creating a Breadcrumb Manually
    Create a breadcrumb while creating a new page, as a Shared Component using the Create Breadcrumb Wizard, or by adding a the breadcrumb region in Page Designer. Add breadcrumb entries from Shared Components.
  • Editing Breadcrumbs
    Edit breadcrumbs and breadcrunb entries in Shared Components and edit breadcrumb attributes in Page Designer.
  • Accessing Breadcrumb Reports
    Access the Grid Edit, Utilization, and History reports by clicking the appropriate tab at the top of the Breadcrumbs page.
