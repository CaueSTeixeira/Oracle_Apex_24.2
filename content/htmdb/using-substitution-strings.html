3.10 Using Substitution Strings

Use substitution strings within templates, region source, or any attribute to pass information and replace a character string with another value.

Note:

If an attribute supports substitutions, Page Designer help includes the section called Additional Information which describes the supported substitution strings. See Viewing Help in Page Designer.
