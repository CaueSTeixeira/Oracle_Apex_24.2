4.2.4.6 Setting Labels

View an issue and then set labels.

To set labels:

  1. View the issue.
    1. Click the Team Development menu.
    2. Click the issue title.

      The Issue Details page appears.


      Description of the illustration issue_details_action_menu.png
  2. From the Actions menu, select Set Labels.
    You can also click the Set Labels icon on far right side of the page.
  3. In the Labels dialog:
    1. Select labels to add to the issue.
    2. Click Apply Changes.
    A new event is added to the Event Timeline and the new labels display under Labels in the far right region.
