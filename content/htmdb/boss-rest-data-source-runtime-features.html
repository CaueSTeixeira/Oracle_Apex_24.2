18.4.8.4 BOSS REST Data Source Runtime Features

Learn about BOSS REST Data Source runtime features.

At runtime, a REST Data Source based on a BOSS REST endpoint supports pagination, data filtering, ordering, and lost update protection. In addition, it also supports enabling total results computation and disabling bulk DML when needed.
