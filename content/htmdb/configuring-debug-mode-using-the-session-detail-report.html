24.2.4 Configuring Debug Mode Using the Session Detail Report

View the Session Detail report to review session information and configure Debug Level and Trace Mode for an active session.

You can configure the Debug Level and Trace Mode for an active session by viewing the Session Detail report. From the Administration menu, select Monitor Activity, Active Sessions, and select an active session.

To learn more, see Viewing the Active Sessions Report in Oracle APEX Administration Guide.
