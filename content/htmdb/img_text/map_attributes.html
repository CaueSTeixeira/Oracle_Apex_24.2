This image shows an earthquake map in Page Designer. In the Rendering tab (or left pane), the map region, Earthquake Map, is selected. In the Property Editor (or right pane), the Attributes tab is selected. Map, Background is set to Default. Map, Height is set to 640. Controls, Navigation Bar is set to Zoom and Compass.
