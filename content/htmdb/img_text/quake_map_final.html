This image shows the final earthquake map and classic report built on the EARTHQUAKE_TABLE. The map displays on the left side includes a Points object layer. Selecting a point displays the earthquake magnitude and location. The following tools display in the upper right corner: Navigation Bar (which contains Zoom In, Zoom Out, and Reset Bearing to North) and Rectangle Zoom. A Scale Bar displays in the lower left corner and a Legend displays beneath the map which contain one entry, Earthquake Map. The Earthquake Table displays on the right side and includes three columns: Id, Title, and Mag.
