5.19.1 Accessing Application Utilities

Access the Application Utilities page by selecting the application and then clicking the Utilities icon.

To access Application Utilities page:

  1. On the Workspace home page, click the App Builder icon.
  2. Select the application.
  3. Click the Utilities icon.

    The Application Utilities page appears.

    Tip:

    To learn more, see Application Utilities Page.
