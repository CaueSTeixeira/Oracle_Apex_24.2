2.5.1 About Workspace Messages

Workspace messages enable administrators to quickly communicate with other users.

Workspace messages display both on the Workspace home page and on the Workspace Administration page.

2.5.2 Defining and Editing Workspace Messages

Define or edit a workspace message from either the Workspace home or the Administration page.

To define or edit a workspace message:
  1. To define a workspace message from Workspace home page:
    1. On the Workspace home page, find the Workspace Message region.
    2. Click the Define Workspace Message icon.
    3. In Message, enter or remove text. Use standard HTML tags to include formatting.
    4. Click Apply Changes.
  2. To define a workspace message from the Workspace Administration page:
    1. Sign in to Oracle APEX.
    2. At the top of the Workspace home page, click the Administration menu and select Administration.
      The Workspace Administration home page appears.
    3. Click the Define Workspace Message icon.
    4. In Message, enter or remove text. Use standard HTML tags to include formatting.
    5. Click Apply Changes.
