2.15 Viewing File Utilization

Identify areas using excessive storage by viewing the File Utilization report.

Each Workspace is allocated a certain amount of storage. Use the File Utilization report to identify areas using excessive storage.

To view the File Utilization report:

  1. Navigate to the Workspace Administration page:
    1. Sign in to Oracle APEX.
    2. At the top of the Workspace home page, click the Administration menu and select Administration.

    The Workspace Administration home page appears.

  2. On the Administration page, click Manage Service.
  3. Under Manage Meta Data, click File Utilization.
  4. Review the report.
