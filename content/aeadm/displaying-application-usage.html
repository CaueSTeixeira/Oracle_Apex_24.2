3.12.11.1.13 Displaying Application Usage

View a summary of APEX application usage.

To see summary information about recent usage of your APEX applications, use the command apex log. 

SQL> apex log

Information also appears for the APEX applications comprising the App Builder itself. These internal applications have ID numbers in the 4000's range. You can gain additional usage insights by directly querying the APEX dictionary view APEX_WORKSPACE_LOG_SUMMARY.
