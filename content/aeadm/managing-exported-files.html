2.1.6 Managing Export Files in the Current Workspace

Use the Manage Export Repository to manage Export files in the current workspace.

Use the Manage Export Repository page in Workspace Administration to download or delete Export files.

To access the Manage Export Repository page:

  1. Navigate to the Workspace Administration page:
    1. Sign in to APEX.
    2. At the top of the Workspace home page, click the Administration menu and select Administration.

    The Workspace Administration home page appears.

  2. On the Tasks list, click Manage Export Repository.
  3. To download a file, click the file name in the Download column..
  4. To delete a file, select the file and click Delete Checked.
