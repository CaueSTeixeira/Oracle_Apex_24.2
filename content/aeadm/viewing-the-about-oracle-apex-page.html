2.1.5 Viewing the About Oracle APEX Page

Access the About Oracle APEX page to view basic product information, including product details, CGI environment details, database information, currently selected character sets, database initialization parameters, and Oracle legal notices.

To view the About Oracle APEX page:

  1. Sign in to APEX.

    The Workspace home page appears.

  2. Click the Help menu and select About.

    The About Oracle APEX page appears and is divided into the following sections:

    • Details:

      • Product Build
      • Schema Compatibility
      • Last DDL Time
      • Host Schema
      • Application Owner
      • Workspace ID
      • Workspace Name
      • Current user
      • Language Preference
      • Current Time (on server)

    • CGI Environment - Provides information about the currently installed web server software such as currently defined parameters and variables.

    • Database Version- Lists details about the currently installed database version.

    • Character Set- Lists currently selected character sets. The selected character set determines the encoding scheme used to display characters on screen.

    • Database Initialization Parameters - View the number of JOB_QUEUE_PROCESSES.

    • Multilingual Engine - Provides information if JavaScript in the database can be used for APEX applications and the schemas of the current workspace.

      The Multilingual Engine (MLE) is only available on Oracle Database 21c and later.

    • Oracle Legal Notices:

      • Copyright Notice

      • License Restrictions Warranty/Consequential Damages Disclaimer

      • Warranty Disclaimer

      • Restricted Rights Notice

      • Hazardous Applications Notice

      • Trademark Notice

      • Third-Party Content, Products, and Services Disclaimer

      • Third-Party Notices
