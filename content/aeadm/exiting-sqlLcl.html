3.12.11.1.3 Exiting SQLcl

Learn how to exit SQLcl.

To exit SQLcl:

  • At the SQL> command prompt enter the command:

    exit

    For example:

    SQL> exit
Disconnected from Oracle Database 21c Express Edition Release 21.0.0.0.0 - Production
Version 21.3.0.0.0
