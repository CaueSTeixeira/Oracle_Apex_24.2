2.7.2 Adding, Editing, and Deleting Extension Menu Links

Add, edit, and delete Extension menu links in Workspace Administration.

  • Adding Extension Menu Links
    Add links to the Extension menu in Workspace Administration on the Manage Service, Links page.
  • Editing Extension Menu Links
    Edit links on the Extension menu on the Create / Edit Link page in Workspace Administration.
  • Deleting Extension Menu Links
    Delete links on the Extension menu on the Create / Edit Link page.

Parent topic: Managing Links on the Extension Menu

2.7.2.1 Adding Extension Menu Links

Add links to the Extension menu in Workspace Administration on the Manage Service, Links page.

Note:

The Extension menu only appears on the menu bar if a Workspace Administrator has added Extension menu links.

To add links to the Extension menu:

  1. Navigate to the Links page:
    1. Sign in to APEX.
    2. On Workspace home page, click the Administration menu and select Manage Service and then Manage Extension Links.

    The Links page appears and displays as an editable interactive gird.

  2. To add a new link to the Extensions menu:
    1. Add a new row to the report. Options include:

      • Add a new row to the end of the report. ClickAdd Row.

      • To add a new row after a selected row. Click Row Actions and select Add Row.

    2. Select and edit the cells in the new row:
      • Display Sequence - Specify the display sequence for the link entry. The sequence determines the display order in the Extensions menu.
      • Label - Enter the label for the link to display in the Extensions menu.
      • URL - Enter a valid URL target for this link. Links can include substitutions. See About the Extension Menu.
      • Public - This attribute only displays in workspaces that are configured to host Extension Applications.

        To make a link visible in the Extension menu of subscribing workspace, set Public to Yes.

      • Description - Enter information about the link.
    3. Click Save.

2.7.2.2 Editing Extension Menu Links

Edit links on the Extension menu on the Create / Edit Link page in Workspace Administration.

To edit links on the Extension menu:

  1. Navigate to the Links page:
    1. Sign in to APEX.
    2. On Workspace home page, click the Administration menu and select Manage Service and then Manage Extension Links.

    The Links page appears and displays as an editable interactive grid.

  2. Find the row and click the Edit icon.
  3. On the Create / Edit Link page:
    1. Name - Enter the label for the link to display in the Extensions menu.
    2. Display Sequence - Specify the display sequence for the link entry. The sequence determines the display order in the Extensions menu.
    3. URL - Enter a valid URL target for this link. Links can include substitutions. See About the Extension Menu.
    4. Public - This attribute only dispslays in Workspaces that are configured to host Extension Applications. To make a link visible in the Extension menu of subscribing workspace, set Public to Yes.
    5. Description - Enter information about the link.
    6. Click Apply Changes.

2.7.2.3 Deleting Extension Menu Links

Delete links on the Extension menu on the Create / Edit Link page.

To delete links on the Extension menu:

  1. Navigate to the Links page:
    1. Sign in to APEX.
    2. On Workspace home page, click the Administration menu and select Manage Service and then Manage Extension Links.

    The Links page appears and displays as an editable interactive gird.

  2. To delete a row:
    1. Find the row containing the link to be deleted and click the Edit icon.
    2. On the Create / Edit Link page, click Delete.
      A confirmation dialog appears. Click OK to confirm the action.

    Tip:

    You can also delete an specific rows by clicking the Row Actions menu and selecting Delete. See Deleting a Row in an Interactive Grid in Oracle APEX End User’s Guide.
