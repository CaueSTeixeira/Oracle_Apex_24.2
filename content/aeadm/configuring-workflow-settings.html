3.5.7 Configuring Workflow Settings

Configure retention periods for tasks and workflows.

  • Configuring Task Retention
    Specify the number of days completed human tasks are retained.
  • Configuring Workflow Retention
    Specify the number of days completed workflow instances are retained.

Parent topic: Configuring Instance Settings

3.5.7.1 Configuring Task Retention

Specify the number of days completed human tasks are retained.

Use the Retention Period in Days attribute to specify the retention period in days for human tasks. Tasks are kept until their retention period is up, and then purged. To learn more about task retention and purging, see About Task Retention and Task Purging in Oracle APEX App Builder User’s Guide.

To specify the retention period for tasks:

  1. Sign in to APEX Administration Services.
  2. Click Manage Instance.
  3. Under Instance Settings, click Instance Settings.
  4. Find Workflow Settings.
  5. In Retention Period Days, enter the number of days completed human tasks are retained in the instance before being purged. The value cannot be greater than 30 days. The default value is 7 days.
  6. Click Apply Changes.

Parent topic: Configuring Workflow Settings

3.5.7.2 Configuring Workflow Retention

Specify the number of days completed workflow instances are retained.

Use the Retention Period in Days attribute to specify the retention period in days for workflow instances. Completed workflows are kept until their retention period is up, and then purged. Terminated and canceled workflows are purged the next time the purge job runs. Active, suspended, and faulted workflow instances are not purged. To learn more about workflow retention and purging, see Workflow Instance Retention in Oracle APEX App Builder User’s Guide.

To specify the retention period for workflows:

  1. Sign in to APEX Administration Services.
  2. Click Manage Instance.
  3. Under Instance Settings, click Instance Settings.
  4. Find Workflow Settings.
  5. In Workflow Retention Period Days, enter the number of days completed workflows are retained in the instance before being purged. The value cannot be greater than 100 days. The default value is 30 days.
  6. Click Apply Changes.
