3.8.1.2 Creating or Editing the Login Message

Instance administrators create or edit the login messages under Messages on the Manage Instance page.

To create or edit a login message:

  1. Sign in to Oracle APEX Administration Services.
  2. Click Manage Instance.
  3. Under Messages, click Define Login Message.
  4. In Message, edit the message text. To delete a login message, delete the message text.
    The message can contain any text and can optionally include HTML formatting.
  5. Click Apply Changes.
