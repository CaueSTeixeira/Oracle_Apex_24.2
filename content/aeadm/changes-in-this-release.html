1 Changes in Release 24.2 for Oracle APEX Administration Guide

All content in Oracle APEX Administration Guide has been updated to reflect release 24.2 functionality and user interface changes.

New Features and Updates

  • Allow DBMS Credentials Usage

    APEX Administration Services includes a new setting, Manage Instance, Security, Allow DBMS Credentials Usage which enables database credentials for all workspaces on the current instance. Enabling this option is required when integrating APEX with Fusion Applications.

    See Enabling Allow DBMS Credentials Usage

  • Extension Menu Automatic Subscription Support

    The Component Availability setting in APEX Administration Services, Manage Workspaces, Existing Workspaces determines whether a workspace can host extensions and publish links to other workspaces. Component Availability now includes a new option, Yes - Automatic Subscription, which enables an Instance Administrator to create public Extension menu entries which are automatically subscribed to all workspaces in the instance.

    See Enabling Extension Menu Subscriptions.
