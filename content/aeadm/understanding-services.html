3.1 Understanding Administration Services

Use Oracle APEX Administration Services (Administration Services) to monitor and administer all workspaces in a hosted instance.

Note:

Many configuration options are available at both the workspace and instance-level. Instance-level settings generally override similar settings found in Workspace Administration.

  • What Is an Instance Administrator?
    Instance administrators manage an entire Oracle APEX hosted instance.
  • Signing In To Administration Services
    Sign in to Oracle APEX Administration Services using the Instance administrator account and password created or reset during the installation process.
  • Overview: Administration Services UI
    Key pages in Administration Services include the Administration Services, Manage Instance, and Manage Workspaces.
