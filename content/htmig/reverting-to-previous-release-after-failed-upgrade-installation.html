C.3.1 Reverting to a Previous Release After a Failed Upgrade Installation

Learn about reverting to Oracle APEX to a previous release in the case of a failed upgrade installation.

In the case of a failed upgrade installation, you may want to revert Oracle APEX to a previous release and then remove the schemas associated with the current release.

  • Verifying If You Have a Previous Release of APEX
    Run a query to verify if you have previous release of Oracle APEX.
  • Reverting the Images Directory
    If you altered your images directory, revert it back to the release you want to revert to. You must point the text alias /i/ back to images directory for the release you want to revert to.
  • Reverting to a Previous Release
    Learn how to revert to a previous release Oracle APEX.
  • Removing the APEX Release Schema
    After you revert to the prior release, remove the Oracle APEX schema.
