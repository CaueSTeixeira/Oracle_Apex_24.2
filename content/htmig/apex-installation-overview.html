3 APEX Installation Overview

Oracle APEX Installation Guide describes how to install Oracle APEX in a self-managed (local) database.

How you sign in and access APEX depends upon your user role and where APEX resides. APEX may reside in a local self-managed Oracle or in an Oracle Cloud Service.
